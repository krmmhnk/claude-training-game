# Claude マスター道場

Claude / Claude Code / GitHub の使い方をクイズ形式で学べるブラウザゲームです。

## ファイル構成

```
claude-training-game/
├── index.html   # 画面レイアウト（HTML）
├── style.css    # デザイン・アニメーション
├── game.js      # ゲームロジック・ミッションデータ
└── README.md    # このファイル
```

## 起動方法

`index.html` をブラウザで開くだけで動きます。サーバー不要。

## ゲーム概要

### 画面構成

| 画面 | 説明 |
|------|------|
| タイトル | キャラ名入力・ゲームスタート |
| キャラカスタム | 見た目の変更（レベルで段階解放） |
| ミッションマップ | ミッション選択・EXP・レベル表示 |
| 依頼書 | ミッションの解説・知識紹介 |
| ミッション | クイズ回答（制限時間あり・バトル演出） |
| クリア | EXP獲得・レベルアップ演出 |

## レベルシステム

| Lv | 必要累計EXP | 解放されるカスタマイズ |
|----|------------|----------------------|
| 1  | 0          | 体の色・髪型（表情） |
| 2  | 120        | 服の色 |
| 3  | 280        | アクセサリー |
| 4  | 490        | 背景カラー / GitHub の島 |
| 5  | 680        | 称号 |
| 6  | 820        | 目の色・髪の色（全ミッションクリア報酬） |

クリア済みミッションを再度クリアしても EXP を獲得できます（復習ボーナス）。

---

## クイズシステム

- 各ミッション **5〜6問**
- 制限時間 **30秒**（残り10秒で赤く点滅）
- 時間切れは不正解扱い（正解を表示）
- バトル演出：勇者が歩き、75%の確率で敵が登場
  - 正解 → 勇者が攻撃して敵を撃破（⭐ エフェクト）
  - 不正解・時間切れ → 勇者がダメージを受ける

## 技術メモ

- フレームワーク・ライブラリなし（純粋な HTML / CSS / JS）
- フォント：[Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P)（Google Fonts）
- キャラクター・敵はインラインSVGでピクセルアート風に描画
- 状態管理は `localStorage`（`claudeGame` キー）に JSON で保存

### GitHub Pages での公開手順

1. GitHub にリポジトリを作成（Public）
2. `index.html` / `style.css` / `game.js` をアップロード
3. Settings → Pages → Branch: main → Save
4. `ユーザー名.github.io/リポジトリ名` で公開完了
